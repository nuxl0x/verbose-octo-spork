[VOS] verbose-octo-spork \ Manual \ math
=======================================
Syntax: (vos) math <operator> <number> <number> <custom>

Operators:
- add ( + )
- sub ( - )
- mult ( * )
- div ( / )
- linear ( y = mx + c )

Using the full versions of any of the operators except linear is also supported by VOS and will be correctly recognised.

There are 2 primary use-cases for the math command, being standard mathematical operations, and linear equations.
In all use cases except for linear equations, the <custom> parameter is unused and is not required to be filled in.

For standard math, you use the operator, followed by the first and second number. You will then recieve the completed equation, including the result.

In linear equations, the first number represents the gradient, and the second number is the y-intercept.
In addition, you are able to include 'c' at the end of a linear equation argument, in the <custom> field, in order to allow the input of custom X coordinates.

By default, the X coordinates are -2, -1, 0, 1 and 2.
